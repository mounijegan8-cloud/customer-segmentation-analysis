# Customer Segmentation Using K-Means Clustering

## Project Overview

This project focuses on customer segmentation using machine learning and data analytics. Customer purchasing behavior is analyzed using total orders, total sales, and total profit.

The K-Means clustering algorithm is used to divide customers into four groups based on their purchasing behavior. The results are visualized using Python and an interactive Power BI dashboard.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- K-Means Clustering
- Matplotlib
- Power BI
- Excel/CSV

## Project Workflow

1. Load the sales dataset.
2. Aggregate data at customer level.
3. Calculate total orders, sales, and profit.
4. Standardize the customer features.
5. Apply K-Means clustering.
6. Generate four customer segments.
7. Visualize the clustering results.
8. Create an interactive Power BI dashboard.

## Customer Segments

The four clusters were interpreted based on their average customer-level metrics:

- Cluster 0 – Very High-Value Customers
- Cluster 1 – Regular Customers
- Cluster 2 – High-Value Customers
- Cluster 3 – Lower-Activity Customers

## Dashboard

The Power BI dashboard includes:

- Total Customers
- Total Sales
- Total Profit
- Customer Distribution by Segment
- Average Sales by Segment
- Average Profit by Segment
- Sales vs Profit by Segment
- Customer Segment Details
- Segment filter

## Files

- `customer_segmentation.py` – Python implementation of K-Means clustering
- `customer_segments_new.csv` – Customer segmentation results
- Screenshots – Power BI dashboard and analysis outputs

## Outcome

The project demonstrates how machine learning can be used to identify customer groups and support data-driven customer analysis.
